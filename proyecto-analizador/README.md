# Analizador Sintáctico e Intérprete DSL - UTN FRM

Este proyecto implementa un analizador léxico, sintáctico e intérprete para un lenguaje específico (DSL) utilizando **Node.js**.

## Estructura del Proyecto
- `proyecto-analizador/ejemplos/`: Contiene los 4 casos de prueba (2 correctos y 2 con errores sintácticos/léxicos).
- `proyecto-analizador/DSL.g4`: Gramática asignada en formato limpio.
- `proyecto-analizador/index.js`: Código del analizador, generador de tablas de tokens, árbol sintáctico e intérprete.
